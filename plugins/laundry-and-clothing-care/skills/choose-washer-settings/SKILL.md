# Choose washer settings

Translate a prepared load into settings the user's exact machine supports. The user operates the appliance; never say the cycle started, finished, drained, or cleaned unless the user confirms it.

## Required inputs

Ask for the controlling garment label, load type/size/soil, detergent product directions, washer make/model, and the relevant manual/control-panel information. If the model is unknown, give only generic decision criteria and ask the user to locate the manual before naming controls.

## Decide settings

1. Confirm the load is compatible. Return to sorting if one item has a stricter label or waterproof/bulky restriction.
2. Choose a cycle that satisfies the label and machine manual. Cycle names vary by model; never translate a generic label directly into a guessed button.
3. Use the lowest compatible temperature and gentlest spin that meet the soil need. Reduce spin for delicate, wrinkle-prone, or distortion-prone items.
4. Respect the machine's stated load limit; bulky bedding and highly absorbent towels may need smaller or single-item loads.
5. Dose detergent from the detergent label, load size/soil, machine type, and local water guidance. Do not “add extra for certainty.”
6. Add pretreat, soak, extra rinse, or special features only for an observed need and when garment/product/manual instructions permit them.
7. State the drying handoff before the user presses Start.

In live mode, give the current control/action and wait for confirmation. Do not provide a fictional button sequence for an unknown model.

## Check and recover

After the user reports completion, check for detergent residue, excess foam, retained odour, colour transfer, distortion, or unusual machine behaviour. A label/manual-permitted extra rinse may address residue; rewash only after identifying the cause. Do not promise that shrinkage or colour loss can be reversed.

For smoke, burning smell, sparks, electrical fault, severe leak, abnormal banging, or a locked/pressurized unsafe condition, stop use and keep away from the machine. Disconnect power only when that can be done without touching water or damaged equipment and the manufacturer/local safety guidance says it is safe; otherwise call professional or emergency help. Do not provide appliance or gas repair instructions.

Sources: [Samsung model/cycle guidance](https://www.samsung.com/us/support/answer/ANS10001016/) and [Hong Kong Consumer Council laundry guidance](https://www.consumer.org.hk/tc/shopping-guide/tips/2022-tips-washing-machine).
