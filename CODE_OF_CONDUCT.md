# Code of Conduct

This project welcomes careful, evidence-backed collaboration. Treat people with respect, discuss behavior and tradeoffs rather than motives, and make room for contributors with different experience levels.

Harassment, threats, discriminatory language, unwanted sexual attention, deliberate disclosure of private information, and sustained disruption are not acceptable in project spaces.

Maintainers may edit or remove abusive contributions and temporarily or permanently restrict participation when needed to keep the project safe. Report conduct concerns privately through the maintainer contact shown on the GitHub profile. Do not include sensitive personal information in a public issue.

Enforcement decisions should be proportionate, documented privately, and limited to project participation. Good-faith technical disagreement and evidence-based criticism are welcome.
